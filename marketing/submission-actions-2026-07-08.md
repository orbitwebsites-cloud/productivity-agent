## Submission Copy Pack

Project name:
ScreenBuddy / Pesto

Tagline:
Your desktop focus Jarvis.

Short description:
Pesto is a Windows desktop companion that tracks local app/window metadata, organizes time into Life Pursuits, and uses Jarvis Mode to help users stay oriented to the goal they chose. If the user drifts too long, Pesto warns them, counts down, then safely minimizes the distraction and restores their previous work context.

What makes it different:
- Proactive, not passive.
- Reversible OS actions, not risky mouse takeover.
- Pursuit-aware, not rigid site blocking.
- Metadata-first, not screenshot-first.

Demo script:
1. Open Pesto and set active pursuit to Tech Job.
2. Work in VS Code/Chrome docs long enough for Pesto to remember the primary work window.
3. Drift to YouTube/Reddit.
4. Warden overlay appears: "outside Tech Job."
5. Countdown ends and Pesto minimizes the distraction.
6. Ask: "Where was I yesterday?"
7. Click "Restore yesterday's workspace."
