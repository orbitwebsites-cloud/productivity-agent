## Submission Copy

Project title:
ScreenBuddy / Pesto

Tagline:
The desktop companion that keeps you pointed at the work you chose.

Short description:
Pesto is a local-first desktop buddy for focus and context recovery. It tracks active app/window metadata, lets users define Life Pursuits, and uses Jarvis Mode to guard the current pursuit. If the user drifts into a distraction, Pesto warns them with a countdown, then safely minimizes the distraction and restores the last work window. No mouse takeover. No destructive actions.

Problem:
Focus tools are either passive trackers that only report after the damage is done, or heavy agents that take over the computer. People need a reversible, personalized companion that helps them stay on task in real time.

Differentiator:
Pesto is proactive but safe. It does not click through websites or close apps. It uses OS-level window management to minimize distractions and restore context.

Demo script:
1. Set active pursuit to Tech Job.
2. Open a work app and let Pesto remember it.
3. Switch to YouTube/Reddit long enough to trigger Warden.
4. Countdown appears.
5. Pesto minimizes the distraction and refocuses the work app.
6. Ask "Where was I yesterday?" and click Restore workspace.

Suggested categories:
- Productivity
- AI Agents
- Developer Tools
- Future of Work
- ADHD / executive-function support, phrased carefully as a workflow tool, not a medical product.
