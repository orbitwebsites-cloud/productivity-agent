# Free Marketing Plan

Positioning:
Pesto is not a computer-use agent that does your job. It is an active executive-function companion that makes sure you do your job.

## Channels

### 1. Reddit problem replies
- Use the researched threads and search routine in `reddit-research.md`.
- 3-5 helpful replies/day.
- Transparent founder identity.
- No mass posting.

### 2. Product Hunt prep
- Build launch page now, launch later after a working downloadable installer and demo video.
- Ask for comments/feedback, not upvotes.
- Founder comment angle:
  "I built this because I kept losing context and drifting from work, but I did not want an AI that takes over my mouse."

### 3. Indie Hackers / Build in Public
- Post build logs:
  - "I made a desktop buddy that minimizes distractions instead of blocking websites."
  - "Why Pesto only minimizes windows, never closes them."
  - "Building a Jarvis for ADHD-ish context switching without making medical claims."

### 4. Hacker News / Show HN
- Only after installer is reliable.
- Title:
  "Show HN: Pesto, a local desktop companion that minimizes distractions"
- HN audience will inspect privacy and local behavior. Lead with metadata-only, reversible actions, no screen pixels by default.

### 5. Devpost / lablab.ai hackathons
- Use `hackathon-targets.md`.
- Do not submit until demo video and public download are ready.

### 6. Short-form videos
- 5 clips:
  1. "I built a desktop buddy that hides YouTube after a countdown."
  2. "The problem with app blockers: they do not know your current goal."
  3. "Pesto is Jarvis, but for executive function."
  4. "Where was I yesterday? Restore workspace demo."
  5. "Why Pesto minimizes, never closes."

## 7-Day Execution

Day 1:
- Finish Jarvis MVP.
- Record rough demo.
- Improve landing page.

Day 2:
- Post 3 transparent Reddit replies.
- Make a 30-second demo GIF.

Day 3:
- Build Product Hunt draft assets.
- Submit to one hackathon only if account + demo are ready.

Day 4:
- Post build log on Indie Hackers / X / LinkedIn.
- Ask for beta testers.

Day 5:
- Reply to new Reddit threads.
- Improve onboarding from feedback.

Day 6:
- Prepare Show HN draft, do not post yet.

Day 7:
- Publish beta link, then ask testers for specific feedback: "Did Warden feel helpful or annoying?"
